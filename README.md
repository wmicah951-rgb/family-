# Family Feud Night · Host & Operator Guide

Static site (no build step) for running the 4 Family Feud PowerPoint games.

- **Operator · board** view: every round laid out like the slide. Tile number here = tile number on screen. Tap tiles and strikes to keep track.
- **Host · rundown** view: every question in order with its answers.
- **How to run the board**: the slide controls.

Edit game content in `data.js`.

## Deploy on Vercel
Import this repo at vercel.com/new. Framework preset: **Other**. No build command, no output directory. Deploy.
